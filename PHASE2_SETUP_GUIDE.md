# HeavyVehiclesWorld – Phase 2 Unity Setup Guide

> Follow these steps in order after cloning the project. No imported 3D models are needed for Phase 2 — primitive placeholder meshes are generated by PrimitiveMeshBuilder.

---

## Section 1: Opening the Project in Unity

1. Install **Unity Hub** (https://unity.com/download)
2. Install **Unity 2022.3 LTS** via Unity Hub → Installs → Add → Archive
   - Minimum: 2022.3.0f1 | Recommended: **2022.3.20f1**
   - Required modules to tick during install:
     - ✅ Android Build Support
     - ✅ Android SDK & NDK Tools
     - ✅ OpenJDK
3. Open Unity Hub → **Projects → Add → Browse** → select `HeavyVehiclesWorld/` folder
4. Click the project to open — Unity will import all packages from `Packages/manifest.json`
   - Expected import time: **2–5 minutes** on first open
   - You will see errors about missing scripts until packages finish importing — this is normal

---

## Section 2: URP (Universal Render Pipeline) Setup

1. **Verify URP is installed:**
   Window → Package Manager → (In Project) → search "Universal RP" → should show 14.x

2. **Create a URP Asset:**
   - Right-click `Assets/Settings/` → Create → Rendering → **URP Asset (with Universal Renderer)**
   - Name it `UniversalRenderPipelineAsset`
   - This creates two files: the pipeline asset and a universal renderer data asset

3. **Assign URP globally:**
   - Edit → Project Settings → **Graphics**
   - Drag `UniversalRenderPipelineAsset` into **Scriptable Render Pipeline Settings**

4. **Assign URP per quality level:**
   - Edit → Project Settings → **Quality**
   - For each quality level (Low/Medium/High/Ultra) → drag the same URP asset into **Render Pipeline Asset**
   - Or create separate URP assets per level for different shadow/post-processing configs

5. **Fix any pink/magenta materials:**
   - Edit → Rendering → **Render Pipeline Converter** → Initialize + Convert to URP

## Section 3: Input System Setup

1. **Enable new Input System:**
   - Edit → Project Settings → Player → **Other Settings**
   - Set **Active Input Handling** → `Both` → Unity will restart
   - After restart, change to `Input System Package (New)` only

2. **Generate C# wrapper (optional — hand-crafted wrapper already exists):**
   - Navigate to `Assets/Settings/HeavyVehiclesInputActions.inputactions`
   - Right-click → **Generate C# Class** → save location: `Assets/Scripts/Controls/`
   - **Important:** If Unity generates a class with a different name, either:
     - Rename `HeavyVehiclesInputActions.cs` to match, OR
     - Delete `HeavyVehiclesInputActions.cs` (the hand-crafted one) and use the generated one

3. **Control scheme bindings** (already in the .inputactions file):

   | Action | Keyboard | Gamepad | Mobile |
   |---|---|---|---|
   | Throttle | W | Right Trigger | Virtual Joystick Up |
   | Brake | S | Left Trigger | Virtual Joystick Down |
   | Steer | A / D | Left Stick X | Left Joystick X |
   | Handbrake | Space | B button | HB Button |
   | Enter/Exit | E | A button | Enter Button |
   | Engine toggle | F | — | Engine Button |
   | Headlights | L | — | Light Button |
   | Horn | H | Y button | Horn Button |
   | Camera switch | C | Right Stick click | Camera Button |
   | Pause | Escape | Start | Pause Button |

## Section 4: Creating the Main Scene

1. **New scene:** File → New Scene → **Basic (URP)**
2. **Save:** File → Save As → `Assets/Scenes/GameScene.unity`
3. **Add Terrain:**
   - GameObject → 3D Object → **Terrain**
   - In Inspector → Terrain Settings: Width = **4000**, Length = **4000**, Height = **600**
   - Position: `(-2000, 0, -2000)` to centre it on world origin
4. **Sun light:**
   - Select the existing **Directional Light**
   - Rotation: `(-30, 60, 0)`, Intensity: `1.2`, Color: warm white `#FFF5E0`
   - Mode: **Mixed** (for baked + real-time shadows)
5. **Add Scene Manager:**
   - Create Empty → name `"SceneManager"`
   - Add **SceneBootstrapper** component
6. **Add Input System:**
   - Create Empty → name `"InputManager"`
   - Add **InputManager** component
7. **Add Game Manager:**
   - Create Empty → name `"GameManager"`
   - Add **GameManager** component
8. **Add Player:**
   - Create Empty → name `"Player"`
   - Add **CharacterController** (radius=0.4, height=1.8)
   - Add **PlayerController** script
   - Add a child **Camera** (position: 0, 1.6, 0 — eye level)

## Section 5: Car Prefab Setup (Step-by-Step)

### 5.1 Build the mesh with PrimitiveMeshBuilder
1. Create Empty → name `"Car"` → position `(0, 1, 0)`
2. Add **PrimitiveMeshBuilder** component
3. Set `Template` → `Car`, tick `Build Now` checkbox
4. The script creates a body, roof, and 4 wheel cylinder children automatically

### 5.2 Add Physics
5. Add **Rigidbody** to Car root:
   - Mass: `1500`, Drag: `0.05`, Angular Drag: `2`
   - Interpolate: `Interpolate`, Collision Detection: `Continuous`
6. Add **WheelCollider** to each of the 4 wheel anchor objects:
   - Radius: `0.35`, Suspension Distance: `0.3`
   - Spring: `35000`, Damper: `4500`, Target Position: `0.5`
   - Forward Friction Stiffness: `1.5`, Sideways Friction Stiffness: `2.0`

### 5.3 Add Scripts
7. Add **CarController** to Car root → assign all 4 WheelColliders and mesh transforms
8. Add **VehiclePhysicsSetup** → create a WheelSuspensionData asset (car preset), assign it
9. Add **EngineAudio** → assign AudioClips for idle/rev
10. Add **VehicleEffects** → assign ParticleSystems (create empty ones if no assets yet)
11. Add **CarPrefabSetupGuide** → check Inspector for any ⚠️ warnings

### 5.4 Add Cameras
12. Add **CameraController** to Car root
13. Create child empties: `"DriverSeat"` (pos 0, 1.2, 0.3) and `"ThirdPersonAnchor"` (pos 0, 3, -6)
14. Create 3 **Cinemachine Virtual Cameras**, assign to CameraController

### 5.5 Add Interaction Trigger
15. Add **VehicleInteractionTrigger** to Car root
16. Add **SphereCollider** (radius=4, Is Trigger=true)

### 5.6 Save as Prefab
17. Drag Car from Hierarchy to `Assets/Prefabs/Vehicles/Car.prefab`

## Section 6: Truck Prefab Setup

Follow the same steps as the Car, with these differences:

| Setting | Car | Truck |
|---|---|---|
| Rigidbody Mass | 1500 kg | 8000 kg |
| Motor Torque | 1500 Nm | 6000 Nm |
| Max Steer Angle | 35° | 25° |
| Wheel Radius | 0.35 m | 0.55 m |
| Suspension Spring | 35,000 | 80,000 |
| Suspension Damper | 4,500 | 8,000 |
| Script | CarController | TruckController |

**Extra objects for Truck:**
- Empty child `"TrailerHitch"` at rear — assign to `Trailer Hitch Point` field
- Empty child `"TipperBed"` (cube 5×0.3×2) — assign to `Tipper Bed` field
- Trailer is a **separate prefab** with its own WheelColliders and TrailerController

## Section 7: Touch UI Canvas Setup

1. Create **Canvas** (Render Mode: Screen Space – Overlay)
   - In Canvas Scaler: UI Scale Mode = `Scale With Screen Size`
   - Reference Resolution: `1920 × 1080`, Match: `0.5`

2. **Left virtual joystick** (bottom-left quadrant):
   - UI → Image (background circle, 180×180, semi-transparent)
   - Child Image (handle circle, 80×80)
   - Add **OnScreenStick** component → Control Path: `<Gamepad>/leftStick`

3. **Right virtual joystick** (bottom-right quadrant):
   - Same setup → Control Path: `<Gamepad>/rightStick`
   - Used for camera look + arm control (JCB/Excavator)

4. **Button strip** (bottom centre):
   | Button | Action |
   |---|---|
   | 🚗 Enter/Exit | EnterExit action |
   | ⚙️ Engine | ToggleEngine action |
   | 💡 Lights | Headlights action |
   | 📯 Horn | Horn action |
   | 🅿️ Handbrake | Handbrake action |

5. Add **MobileInputUI** script to Canvas root → assign all button references

## Section 8: Testing in the Editor

### Expected keyboard controls:
| Key | Action |
|---|---|
| W / S | Throttle / Brake |
| A / D | Steer left / right |
| Space | Handbrake |
| E | Enter / Exit vehicle |
| F | Toggle engine on/off |
| L | Toggle headlights |
| H | Horn |
| C | Cycle camera (3rd → 1st → FreeLook) |

| PageUp / PageDown | Manual gear shift |

### What you should see:
- ✅ Player walks around with WASD
- ✅ Walking near a vehicle shows "Press E to Enter" prompt
- ✅ Pressing E enters the vehicle, player goes invisible
- ✅ W accelerates, engine sound pitch rises with RPM
- ✅ S brakes, Space drifts (handbrake)
- ✅ Wheel meshes rotate and steer correctly
- ✅ L turns headlights on/off
- ✅ Tipper bed raises/lowers (Truck) on UI button
- ✅ C cycles between third-person, first-person, free-look cameras

### Console checks:
- No errors in Console (warnings about missing clips/prefabs are okay)
- CarPrefabSetupGuide will log warnings for any unassigned references
